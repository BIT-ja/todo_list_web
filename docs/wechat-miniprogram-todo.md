# 微信小程序上线阻断项

这些事项需要在微信公众平台、域名服务商或微信开发者工具中完成，代码无法自动代办。

## 必须完成

- [ ] 获取当前 AppID 对应的 `AppSecret`
  - 路径：微信公众平台 -> 开发管理 -> 开发设置。
  - 写入后端生产环境变量 `WECHAT_APP_SECRET`。
  - 不要提交到 Git。

- [ ] 完成个人主体小程序备案
  - 准备身份证正反面、本人手机号、邮箱。
  - 在微信公众平台的小程序备案入口提交。
  - 关注工信部短信核验，通常需要在短信有效期内完成。

- [ ] 准备已备案 API 域名
  - 建议：`https://api.<你的域名>.com/todo/api`
  - 域名主体、备案主体和小程序主体尽量保持一致。
  - 配置受信任 HTTPS 证书。

- [ ] 在微信后台配置 request 合法域名
  - 路径：微信公众平台 -> 开发管理 -> 开发设置 -> 服务器域名。
  - 添加域名，例如：`https://api.<你的域名>.com`
  - 微信后台通常只配置域名，不配置 `/todo/api` 路径。

- [ ] 替换小程序 API 地址
  - 文件：`miniprogram/utils/config.js`
  - 将 `API_BASE_URL` 从 IP 地址替换为备案域名。

- [ ] 配置后端生产环境变量
  - `WECHAT_APP_ID=wxc71649546fe484cf`
  - `WECHAT_APP_SECRET=<微信后台获取>`
  - `JWT_SECRET=<生产随机强密钥>`

- [ ] 在微信公众平台填写隐私保护指引
  - 用户标识：微信 openid、本地用户 ID、用户名。
  - 组织信息：组织名称。
  - 用户内容：待办标题、详情、评论。
  - 位置信息：用户选择的待办地点和经纬度。
  - 使用目的：登录、组织协作、待办管理、地点导航。

- [ ] 微信开发者工具真机验证
  - 微信一键登录。
  - 首次加入组织。
  - 绑定已有账号。
  - 新建/编辑/删除待办。
  - 右滑完成/恢复。
  - 左滑置顶/加急/删除。
  - 长按同优先级排序。
  - 多地点选点和导航。
  - 评论。
  - `facai` 分类后台。

## 建议完成

- [ ] 准备审核测试账号
  - 推荐单独创建一个审核账号，不直接使用个人主账号。
  - 确保审核账号能看到主要功能。

- [ ] 准备小程序基础资料
  - 名称。
  - 头像。
  - 简介。
  - 服务类目，建议从工具/效率方向选择，最终以微信后台可选项为准。

- [ ] 准备发布说明
  - 说明这是组织内协作待办工具。
  - 说明位置能力仅用于待办地点选择和导航。

- [ ] 增加后端备份流程确认
  - 本次数据库变更只新增字段和索引，但生产更新前仍建议备份 SQLite 数据库。
